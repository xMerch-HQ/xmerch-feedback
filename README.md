xMerch gives creators, local businesses, schools and brands a store that sells, ships and gets paid: products, drops and live auctions, with card or wallet checkout.

**This repository is where you report bugs and send feedback about xMerch.** The xMerch code itself is private.

## Report a bug

1. Search [existing issues](https://github.com/mworks-proj/xmerch-testing/issues?q=is%3Aissue) first.
2. Open a [bug report](https://github.com/mworks-proj/xmerch-testing/issues/new?template=bug_report.yml) and include the page link, the steps, and the order number or transaction hash if it's about a payment.
3. Never post card details, wallet secrets, or another person's information.

Have an idea instead? Open a [feature request](https://github.com/mworks-proj/xmerch-testing/issues/new?template=feature_request.yml).

## Report a security issue

**Don't open a public issue.** Use [Report a vulnerability](https://github.com/mworks-proj/xmerch-testing/security/advisories/new) so only the xMerch team sees it. Scope and rules are in [SECURITY.md](SECURITY.md).

## What you can run on xMerch

| | |
|---|---|
| [Stores](https://www.xmerch.app/apply/vendor) | Sell merch, drops, services or team gear, and get paid by card, Apple Pay, Cash App or wallet. |
| [Teams](https://www.xmerch.app/teams) | A free online store for your team, club, league or school: order deadlines, team orders with sizes and player names. |
| [Events](https://www.xmerch.app/events) | Tickets and registrations for car shows, banquets and meetups, every ticket type on one event page. |
| [Auctions](https://www.xmerch.app/auctions) | Live auctions for high-ticket items: scheduled lots, live bids, bidders checked for funds. |
| [Atelier](https://www.xmerch.app/atelier) | A luxury store for one featured watch, with a full-screen configurator and 360° view. |
| [Developers](https://www.xmerch.app/developers) | Scaffold Xaman-signed checkout and donation apps on Xahau and XRPL with the [`xmerch`](https://www.npmjs.com/package/xmerch) CLI. |
| [DEX](https://dex.xmerch.app) | The xMerch non-custodial DEX: connect your Xaman wallet and swap directly onchain. |

See everything, and what each plan includes, on [Features](https://www.xmerch.app/features). Ready to sell? [Start selling](https://www.xmerch.app/apply/vendor).
