**This repository is where you report bugs and send feedback about xMerch.** The xMerch code itself is private.

## Report a bug

1. Search [existing issues](https://github.com/xMerch-HQ/xmerch-feedback/issues?q=is%3Aissue) first.
2. Open a [bug report](https://github.com/xMerch-HQ/xmerch-feedback/issues/new?template=bug_report.yml) with the page link, the steps, and the order number or transaction hash if it's about a payment.
3. Never post card details, wallet secrets, or another person's information.

Have an idea instead? Open a [feature request](https://github.com/xMerch-HQ/xmerch-feedback/issues/new?template=feature_request.yml).

## Report a security issue

**Don't open a public issue.** Use [Report a vulnerability](https://github.com/xMerch-HQ/xmerch-feedback/security/advisories/new) so only the xMerch team sees it. Scope and rules are in [SECURITY.md](SECURITY.md).

## Build on xMerch

Scaffold Xaman-signed checkout and donation apps on Xahau and XRPL with the [`xmerch`](https://www.npmjs.com/package/xmerch) CLI:

```bash
pnpm dlx xmerch create
cd xbase-project
pnpm dev
```

Templates, commands and resources are on [xmerch.app/developers](https://www.xmerch.app/developers). CLI bugs go here too: pick **xmerch CLI** in the bug report.

## What runs on xMerch

Online stores, team orders with deadlines and player names, event tickets and car show registration, live auctions, the Atelier watch configurator, and the [xMerch DEX](https://dex.xmerch.app). Checkout by card, Apple Pay, Cash App, or XRP and Xahau with Xaman. See [Features](https://www.xmerch.app/features), or [start selling](https://www.xmerch.app/apply/vendor).
